# Runs

Diseños de `../test-design/` **llenados con resultados reales** de una corrida — nunca en blanco.

Naming: `QA_RUN_###.#-<feature>.md` — `###` = id consecutivo (asignado en la primera corrida,
estable por feature), `.#` = iteración (+1 en cada re-run hasta Pass). Ver
[`../README-QA-SCHEME.md`](../README-QA-SCHEME.md) — regla de red-flag: `.#` no debe superar 3.
